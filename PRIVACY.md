# Política de Privacidade e Minimização de Dados (LGPD / GDPR)

1. **Minimização de Dados:** O sistema de licenciamento utiliza identificadores pseudonimizados via `HMAC-SHA256` com separação de domínio.
2. **Zero Coleta de Código ou Prompts:** Nenhum código-fonte, histórico de conversa, arquivo de repositório ou credencial de projeto é transmitido ao servidor de licenciamento.
3. **Dados Processados na Ativação:** Apenas hash do e-mail autorizado, identificador público do dispositivo, versão do produto e carimbo de tempo de auditoria.
