# Política de Segurança e Reporte Responsável (SECURITY.md)

## Compromisso de Segurança
Todos os artefatos oficiais do SquadAI Harness são assinados digitalmente com esquema híbrido (`Ed25519 + ML-DSA-65`) e acompanhados de checksums `SHA-256`, SBOM CycloneDX 1.5 e proveniência SLSA v1.0.

## Como Reportar uma Vulnerabilidade
Não abra issues públicas contendo detalhes exploráveis. Utilize a aba **Security Advisories (Private Vulnerability Reporting)** deste repositório no GitHub para envio confidencial à equipe de resposta a incidentes.
