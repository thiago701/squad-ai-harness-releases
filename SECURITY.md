# Política de Segurança e Reporte de Vulnerabilidades (SECURITY.md)

## Integridade dos Pacotes
Todos os pacotes oficiais publicados neste repositório são acompanhados de checksums `SHA-256`, inventário de componentes (SBOM CycloneDX 1.5) e atestado de proveniência (SLSA v1.0).

## Como Reportar uma Vulnerabilidade
Não abra issues públicas contendo detalhes sensíveis. Utilize a aba **Security Advisories (Private Vulnerability Reporting)** deste repositório no GitHub para contato direto com a equipe responsável.
