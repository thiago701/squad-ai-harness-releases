# Changelog Oficial

## [v0.9.112] - 2026-11-01 — SquadAI Harness v0.9.112
### Adicionado
- **Instalador Enxuto de Arquivo Único (`setup-squad-ai.sh`):** suporte completo para instalar, reinstalar, auditar e desinstalar via Git Bash sem pastas extras e sem depender do Windows PowerShell.
- **Auditoria de Homologação Integrada (`./setup-squad-ai.sh --audit`):** verificação automatizada em 8 Gates com ensaio em Sandbox isolado e geração do laudo `homologation-audit-report.json` para equipes de Segurança da Informação.
- **Especialistas de Investigação de Erros e Observabilidade:** aprimoramentos nos fluxos de diagnóstico de falhas de aplicação, análise de logs e validação de testes.
- **Integração Multi-IDE via MCP:** sincronização compatível com 12 ferramentas e assistentes de desenvolvimento em Windows, Linux e macOS (incluindo GitHub Copilot Agent).
