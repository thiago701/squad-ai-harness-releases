# Guia de Instalação Multiplataforma (v0.8.3)

## Pré-requisito Obrigatório
Toda instalação requer conectividade HTTPS (TLS 1.3) ao servidor de licenciamento na ativação inicial (ou manifesto corporativo assinado no modo *air-gapped* empresarial).

## Instalação no Windows (Pacote Zero-EXE e Zero-PowerShell)
1. Baixe `SquadAI-Installer-Windows-v0_8_3.zip` na seção **GitHub Releases**.
2. Confira o hash `SHA-256` contra `manifests/releases/SHA256SUMS.txt`.
3. Extraia o arquivo e execute via **Windows CMD** (`Instalar-SquadAI.cmd`), **Git Bash** (`./setup-squad-ai.sh`) ou abra diretamente o **Wizard GUI HTML** (`SquadAI-Wizard-GUI.html`).
4. Informe seu e-mail autorizado para concluir os 13 passos de ativação e verificação pós-instalação.
